====================================================================
           Brain Tumor MRI AI System - دليل التشغيل على ويندوز
====================================================================

المتطلبات الأساسية:
-------------------
1. تثبيت برنامج Python على الجهاز (يفضل إصدار 3.12.4 (64-bit)).
2. التأكد من وجود ملف الموديل في المسار التالي داخل مجلد المشروع:
   source\Image_Detection_Model.h5

--------------------------------------------------------------------
خطوات التشغيل خطوة بخطوة:
--------------------------------------------------------------------

الخطوة 1: فتح موجه الأوامر (Terminal / CMD / PowerShell)
-------------------------------------------------------
- افتح مجلد المشروع (brain-tumor-mri-ai-system).
- من أعلى الشاشة اكتب `cmd` في شريط مسار المجلد (Address Bar) واضغط Enter، أو اضغط كليك يمين واختر "Open in Terminal".


الخطوة 2: إنشاء البيئة الافتراضية (Virtual Environment)
--------------------------------------------------------
اكتب الأمر التالي في موجه الأوامر واضغط Enter:

    py -3.12 -m venv .venv


الخطوة 3: تفعيل البيئة الافتراضية
-----------------------------------
* إذا كنت تستخدم PowerShell:
    .\.venv\Scripts\Activate.ps1

* إذا كنت تستخدم Command Prompt (CMD):
    .venv\Scripts\activate.bat


الخطوة 4: تثبيت المكتبات المطلوبة
----------------------------------
اكتب الأمر التالي لتثبيت المكتبات الخاصة بالمشروع:

    pip install -r requirements.txt


الخطوة 5: تشغيل التطبيق
------------------------
اكتب الأمر التالي لتشغيل التطبيق:

    python app.py


الخطوة 6: فتح الواجهة في المتصفح
---------------------------------
بعد تشغيل الأمر، سيظهر لك رابط محلي على الشاشة مثل:
    http://127.0.0.1:7860

انسخ الرابط وافتاحه في المتصفح (Chrome / Edge / Firefox) لرفع صورة أشيّة الرنين المغناطيسي وتجربتها.
